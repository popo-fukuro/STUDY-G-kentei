## 3. 受験方法

### オンライン試験（自宅受験）の流れ

1. **受験チケットを買う**（2023年7月からチケット制。購入から**1年間**有効）
2. 申込期間中に、受けたい回を**予約**する
3. 試験当日、自宅のPCからブラウザで受験（Webカメラ・マイクは不要）
4. 約2〜3週間後に合否メール → 合格なら合格証・オープンバッジ発行

### 会場試験（テストセンター）の流れ

1. 会場試験専用の受験者サイト（CBT-Solutions）でアカウント登録
2. 会場と日時を選んで申込（**受験日の3日前23:59まで**）
3. 会場のPCで受験（試験時間は120分）

### 注意点

- オンラインと会場は**別システム**。それぞれアカウント登録が必要で、申込後にオンライン⇔会場の変更・振替はできない。
- 受験規約で、なりすまし・カンニング・他人の援助などの**不正行為は禁止**。疑われると結果が取り消されることがある。
- 時間がとても短いので、調べながら解く前提では間に合わない。**知識で即答できる状態**をめざす。

### 2024年改訂（シラバス2024）のポイント

- 生成AIの広がりを受けて、**基盤モデル・言語モデル**など生成AIに必要な技術を追加した。
- **法律・倫理**で「ディープラーニングを使う人が理解すべき点」をはっきりさせ、AI倫理・AIガバナンスを大きく拡充した（透明性・民主主義・環境保護・労働政策など）。
- 追加された語の例：LLM、MSE・RMSE・MAE、Contrastive Loss、KL情報量、連鎖律、レイヤー正規化、エルマンネットワーク、教師強制、Multi-Head Attention、VQ-VAE、話者識別、RLHF、Diffusion Model、NeRF、自己教師あり学習、破滅的忘却 など。
- 削除された語の例：ENIAC、ロジック・セオリスト、第五世代コンピュータ、深層信念ネットワーク、制限付きボルツマンマシン、OCR、IoT、プラトー、Parts Affinity Fields など。**旧シラバス向けの本やサイトには、もう出ない語が混ざっている。**

## 7. 出題傾向

> 分野ごとの出題比率は公式には発表されていない。以下は公式の例題・シラバス改訂の方向性・2026年の試験形式から読みとれる傾向。

### 公式例題（20問）の分野の配分

| 大項目 | 問題数 |
|---|---|
| 人工知能とは／人工知能をめぐる動向 | 1／2 |
| 機械学習の概要 | 2 |
| ディープラーニングの概要 | 2 |
| ディープラーニングの要素技術 | 3 |
| ディープラーニングの応用例 | 3 |
| AIの社会実装に向けて／数理・統計 | 1／2 |
| AIに関する法律と契約／AI倫理・AIガバナンス | 2／2 |

→ どこか1分野に偏らず、**全範囲からまんべんなく**出る前提で準備する。

### 押さえておきたい傾向

1. **生成AI・Transformer・LLM まわりが重い**：Self-Attention、BERTとGPTの違い、RLHF、拡散モデル、基盤モデル、マルチモーダル。
2. **法律・倫理の比重が高い**：2024年改訂で18項目に拡大。個人情報保護法の用語の区別、著作権法とAI、契約の型（請負／準委任）、ガイドラインの名前と考え方。
3. **用語の区別問題**：似た名前の手法の違い（例：バギングとブースティング、L1とL2、適合率と再現率、セマンティック／インスタンス／パノプティックセグメンテーション）。
4. **人名・年号・モデル名**：ダートマス会議（1956年）、ILSVRC 2012（AlexNet）、AlphaGo など。
5. **簡単な計算**：混同行列から適合率・再現率・F値、畳み込み層の出力サイズ、期待値・確率など。電卓レベル。
6. **時事・最新動向**：国内外のAI規制・ガイドライン（次の「8」）。
7. **時間との勝負**：1問約41秒。長い文章題でも、キーワードを拾って即答する練習が必要。

## 9. 勉強法（このサイトでの進め方）

### 基本の流れ

```
講義を読む → 確認テスト → わからない所を質問（Q&Aノート化） → 一問一答で反復 → 模擬試験
```

1. **講義（全28回）**：シラバスの全キーワードを、図解つきで1回ずつ学ぶ。
2. **確認テスト**：各回の最後。答えは折りたたみ。間違えた問題に印をつける。
3. **Q&Aノート**：わからなかった所は質問 → 解説ページとしてサイトに残る。
4. **一問一答**：用語を見た瞬間に意味が出てくるまで回す（1問41秒対策）。
5. **総仕上げ（第28回）**：模擬試験で時間配分を練習し、網羅チェック表で取りこぼしを潰す。

### コツ

- **似た用語はセットで覚える**：講義の「似た用語との違い」表を重点的に。
- **人名・年号・モデル名は年表で**：講義のまとめ表を一問一答に回す。
- **法律・倫理を後回しにしない**：2024年改訂で18項目に広がった。暗記で確実に取れる分野。
- **カンペに頼らない**：1問41秒では調べる時間がない。即答できる知識を作る。
- **公式の例題（20問）は必ず解く**：形式に慣れる。ただし1.4版で消えた語（ChatGPT など）を含む問いがある点に注意。
- 必要な勉強時間は民間の解説で「30〜50時間」程度とされることが多い（公式の数字ではない）。このサイトの講義は合計 **約40時間**。

### 試験当日のコツ

- 1周目は**わからない問題は即飛ばす**（見直しフラグを使う）。
- 計算問題・長文問題は後回しにして、知識問題で点を積む。
- 残り10分で、飛ばした問題に**必ず何かマーク**する（空欄はもったいない）。
