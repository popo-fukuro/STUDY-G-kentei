# 一問一答

用語を見た瞬間に意味が出てくるまで回すためのページ。本番は1問約41秒なので、**即答できる知識**を作る。

<div class="g-chips">
<span class="g-chip">講義が進むたびに追加</span>
<span class="g-chip">答えはタップで開く</span>
</div>
</div>

!!! tip "使い方"
    - 問題を見て、答えを声に出してから開く。
    - 3回連続で即答できたら、その問題は卒業。
    - 間違えた用語は、講義の「まとめ」表とQ&Aノートで見直す。
