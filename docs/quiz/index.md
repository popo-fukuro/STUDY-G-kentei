### 第1回 人工知能とは？ 定義と「AIの難問」

[講義を開く](../lectures/01-what-is-ai.md)

??? question "Q. AIで実現された技術が「ただの自動化」とみなされ、AIと呼ばれなくなる現象は？"
    **A. AI効果** — 「AIのゴールが先へ逃げる」現象

??? question "Q. 人工知能・機械学習・ディープラーニングの包含関係は？"
    **A. AI ⊃ 機械学習 ⊃ ディープラーニング** — ディープラーニングは機械学習の一種

??? question "Q. ディープラーニングが従来の機械学習と大きく違う点は？"
    **A. 特徴量をデータから自動で学ぶこと** — 従来は人が特徴量を設計した

??? question "Q. 環境を観測し、目的に向けて行動を選んで実行する主体を何という？"
    **A. エージェント** — 観測（センサー）→判断→行動（アクチュエータ）

??? question "Q. 「人工知能」という言葉が研究分野の名前として使われ始めた1956年の研究集会は？"
    **A. ダートマス会議** — 提案者はマッカーシー、ミンスキー、ロチェスター、シャノン

??? question "Q. チューリングテストを提案したのは誰？ 何年？"
    **A. アラン・チューリング、1950年** — 論文「計算する機械と知性」の「模倣ゲーム」

??? question "Q. チューリングテスト形式で最も人間らしいプログラムを競う大会は？"
    **A. ローブナーコンテスト** — 1991年開始、2019年が最後。金・銀メダルは授与されず

??? question "Q. 「中国語の部屋」を考えたのは誰？ 何を批判した？"
    **A. ジョン・サール（1980年）、強いAI** — 記号操作ができても理解しているとは限らない

??? question "Q. サールの「強いAI」とは？"
    **A. 本当に心をもち、理解しているAI** — 弱いAI＝道具としてのAI。汎用AIとは観点が違う

??? question "Q. 関係あることだけを選び出して考えるのが難しいという問題は？"
    **A. フレーム問題** — マッカーシーとヘイズ（1969年）。ロボットの例えはデネット

??? question "Q. 記号と実世界の意味を結びつけられないという問題は？ 提起者は？"
    **A. シンボルグラウンディング問題、ハルナッド（1990年）** — 例：シマウマ＝シマ＋ウマ

??? question "Q. 知能の成立には体を通した経験が必要だとする考え方は？"
    **A. 身体性** — シンボルグラウンディング問題を解く手がかり

??? question "Q. 第1次AIブームの限界を表す「おもちゃの問題」とは？"
    **A. トイ・プロブレム** — 迷路・パズルは解けても現実の問題は解けない

??? question "Q. エキスパートシステム（第2次AIブーム）の壁になった問題は？"
    **A. 知識獲得のボトルネック** — 専門家の知識をルールに書き出しきれない

??? question "Q. 人が書いた文法規則と辞書で訳す機械翻訳は？"
    **A. ルールベース機械翻訳** — 1954年ジョージタウン大学とIBMの実験

??? question "Q. 対訳データから単語や句の対応の確率を学んで訳す機械翻訳は？"
    **A. 統計的機械翻訳** — 翻訳モデル×言語モデル。2016年にGoogleはニューラルへ

??? question "Q. シンギュラリティが2045年に来ると予測したのは誰？"
    **A. レイ・カーツワイル** — 2005年『シンギュラリティは近い』、収穫加速の法則
